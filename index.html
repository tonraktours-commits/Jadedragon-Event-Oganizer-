03 / CASE STUDY

จากโจทย์

เราเริ่ม Case Study V1.1 ด้วยโครงแบบ Challenge → Scope → Execution → Result เพื่อให้ลูกค้าเห็นวิธีคิดและความสามารถในการบริหารจริง

CASE 01 / SURAT ACADEMIC 2025

One team. Multiple production layers.

  • Challenge: งานวิชาการที่ต้องควบคุมภาพรวม เวที และลำดับกิจกรรมพร้อมกัน
  • Scope: Event management, stage, run team, technical coordination
  • Execution: วาง Run of Show, technical cue และทีมประสานจุดปฏิบัติการ
  • Result: สร้าง flow งานที่ชัดเจนและภาพรวมการจัดงานเป็นมาตรฐานเดียวกัน
